# Verwaltung der Kundendaten

# Einleitung 
Diese App geht davon aus, dass ein Friseursalonbetreiber die Kontaktdaten seiner Kunden erfassen möchte. Er möchte, dass seine Kunden ihre Daten in dieser App eingeben, damit er sie jederzeit erreichen kann. Er beabsichtigt, ihnen saisonale Grüße, gelegentliche Glückwünsche (z. B. zum Geburtstag) zu senden sowie sie über Sonderangebote zu informieren. Er verwaltet die Datenbank und verfügt über uneingeschränkte Zugriffsrechte, um alle Daten einzusehen. Die Kunden haben eingeschränkte Rechte und können ihre Daten lediglich hinzufügen, anzeigen, aktualisieren und löschen. Die Startseite dient der Kundenanmeldung oder der Erstellung eines neuen Kontos. Dort kann sich der Salonbetreiber auch über den Bereich „Admin“ anmelden.
Das Projekt wurde mit Java entwickelt.

# Allgemeine Beschreibung des Projektziel
Ein Friseursalon möchte eine Sammlung der Kunden haben, die ein Online-Konto bei ihm angelegt haben. Der Grund dafür ist, den Kunden Nachrichten über Werbeaktionen und besondere Grüße während einiger saisonaler Feste des Jahres zu schicken. Der Salon möchte zu diesem Zweck eine GUI-Anwendung sowie eine Standarddatenbank, in der die Informationen gespeichert werden. Er möchte auch, dass die Daten angezeigt, aktualisiert und gelöscht werden können.

# Ist-Analyse
Derzeit hat der Salon keine Sammlung seiner Kunden. Das macht es für den Inhaber schwierig, mit seinen Kunden zu kommunizieren, und er hat viele von ihnen verloren. Er glaubt, dass eine gute Kommunikation mit seinen Kunden das Geschäft ankurbeln wird, aber er hat keine Ahnung, welche Software er dafür einsetzen soll.

# Soll-Analyse
Als Softwareentwickler würde ich Java für die Entwicklung der App verwenden. Die IDE wäre Intellij und die Community Edition ist dafür ausreichend. Ich würde das JavaFX-Rahmenwerk verwenden, um die grafische Benutzeroberfläche zu realisieren. Um die GUI-Schnittstelle zu verschönern, würde ich die CSS verwenden. Um die Daten persistent zu machen, würde ich Mariadb in XAMPP verwenden.
Die Kunden können zwar Konten anlegen, aber sie können die Kundenliste nicht einsehen. Der Salonbesitzer hätte jedoch ein Administratorrecht, um die Liste der registrierten Kunden einzusehen.
